# 正式上线产品差异化与生成后交互方案

更新日期：2026-10-17  
产品：MakerMuse / 城市木刻师  
已确认目标：实际切穿的镂空作品，保留木料连成整体。  
状态：待实施的正式产品方案。本次根据最新代码重整文档，不修改业务代码。

## 1. 定位、范围与差异化

> 把用户确认过的真实地点或照片，变成可编辑、可检查、适配制作条件的镂空纪念作品。

产品主要任务是让用户选对地点，得到第一版设计，保留满意部分，修改细节与文字，验证镂空结构，保存作品并获得一致的制作文件。

与直接对话生图相比，正式产品应把以下能力做成默认流程：

1. **地点与素材有依据：** 确认的城市、建筑和来源持续绑定作品。
2. **修改可控：** 修改文字、尺寸和相框不重新抽取建筑，局部修复能预览和撤销。
3. **镂空结构可计算：** 检查最终保留材料的连接、桥宽、孔洞和刀缝影响。
4. **交付可复核：** 预览、导出文件、检查报告对应同一设计版本与制作配置。
5. **成果能积累：** 作品可以保存、恢复、复用，已验证材料配置和实际制作反馈持续改善服务。

不能把这些表述为所有 LLM 永远无法做到。产品优势是稳定整合来源、算法、编辑与交付，减少用户自己组织工具和检查文件的负担。单独增加提示词、模型或下载 SVG，不足以形成上述能力。

本方案面向正式上线，不以演示能出图作为完成标准；不以先上线表面雕刻替代已确认的镂空方向。

## 2. 统一镂空语义

默认采用正形剪影：

- 黑色成品预览表示保留木料，包括建筑、文字、支撑和相框。
- 成品内部白色区域表示需要切穿移除的材料。
- 成品外部为余料区域。
- 加工路径单独预览，切穿的是材料边界，不能把预览黑色直接当成填充雕刻指令。
- 表面雕刻可以作为附加细节，不能代替真实孔洞。

文字同样遵守该定义：保留黑色 A、O、P 时，白色内孔通常是需要移除的区域，不应一律给白孔加桥；需要检查的是黑色保留部分与支撑是否连接。以后若支持「挖空字母、保留字母内芯」的负形模板，应另建拓扑规则。

用户界面默认镂空，无须让普通用户反复区分专业术语；只收集尺寸、材料、厚度、设备或制作服务等有实际影响的信息。

检索整改详见[需要修改的搜图问题](城市图片检索可靠性方案.md)。本方案不重复建设已完成的检索纠错，也不假定这些改动已经完成实体正确性验证。

## 4. 各能力由什么实现

| 能力 | 主要实现方式 | Prompt 的作用 | 用户可见结果 |
| --- | --- | --- | --- |
| 锁定真实建筑 | 地点数据、实体核验、前后端契约 | 提取意图、约束唯一主体 | 参考图、城市与建筑明确可查 |
| 生成镂空草稿 | 图像模型与预处理 | 黑色材料、白色开孔、单主体 | 可辨识的第一版设计 |
| 修改文字 | 字形与排版算法、作品模型 | 仅用于解析一句话操作 | 即时更新文字，建筑不重新生成 |
| 换框和改尺寸 | 参数化布局、几何算法、前端 | 通常不需要 | 布局更新，检查状态重算 |
| 减少细节 | 保形简化、尺度过滤、几何复核 | 可辅助提出风格要求 | 简化前后对比 |
| 加粗与加桥 | 局部偏置、桥接候选、材料拓扑 | 可解释或建议，不能判定合格 | 标记修复位置并预览 |
| 局部视觉修改 | 选区、模型编辑、合成与差异检查 | 描述选区内目标 | 生成新主体版本，允许拒绝 |
| 制造检查 | 数值与拓扑算法、配置与实测 | 不承担数值保证 | 具体问题位置、尺寸与结果 |
| 保存、撤销和重试 | 后端、存储、版本与任务服务 | 不需要 | 不丢作品、不被旧任务覆盖 |
| 制作交付 | 轮廓导出、软件验证与材料测试 | 不需要 | 与预览一致的制作文件 |

改 Prompt 可以改善草稿质量，但不能替代材料合并、连接检测、切割导出、版本管理和实测。

## 5. 正式产品的主流程

```text
输入城市记忆 / 上传照片
  → 必要时确认地点、建筑或照片主体
  → 保存任务与参考素材
  → 生成第一版镂空设计
  → 编辑建筑细节、文字、相框和尺寸
  → 确认材料与设备配置
  → 检查最终镂空结构
  → 预览修复、接受或调整
  → 保存最终版本
  → 导出设计文件 / 通过检查的制作包
  → 可选上传实物反馈
```

生成前只确认影响地点身份和主体选择的必要信息。已知制作尺寸或材料时提前应用；用户不懂设备时允许先编辑保存，但不显示某设备已验证通过。

只有制作条件不足时阻止生成「已验证制作包」，不能禁止用户保存自己的设计草稿。

## 6. 生成后交互：把完成页改成编辑工作区

### 6.1 默认界面

| 区域 | 功能 |
| --- | --- |
| 中央作品 | 成品保留材料预览、缩放、参考图对照 |
| 来源摘要 | 已确认城市、建筑、实际参考素材、创作模式 |
| 常用编辑 | 细节、连接、文字、相框、尺寸 |
| 一句话修改 | 自然语言解析成受支持的结构化操作 |
| 制作设置 | 材料、厚度、尺寸、设备或制作服务 |
| 检查与修复 | 标出问题，比较修复前后，接受或撤销 |
| 版本与交付 | 保存、恢复、比较、导出 |

常用操作优先，专业配置按需展开。用户看到的是想完成的动作，不要求理解布尔运算、轮廓嵌套等实现细节。

### 6.2 每个操作如何执行

| 用户操作 | 默认执行 | 是否重调图像模型 | 后续检查 |
| --- | --- | --- | --- |
| 改城市名、日期、纪念语 | 更新文字、重算字形和布局 | 否 | 缺字、溢出、与支撑连接 |
| 换相框 | 切换参数模板并重新合并材料 | 否 | 边距、桥宽、主体与框连接 |
| 调整尺寸 | 物理坐标重排与缩放 | 否 | 新尺寸下全部制造条件 |
| 减少细节 | 保形简化、处理细孔和小特征 | 默认否 | 可辨识度、连接、孔洞 |
| 加粗连接 | 局部增厚，避免全图膨胀 | 默认否 | 新桥宽和相邻孔洞 |
| 添加连接桥 | 生成候选桥并确认 | 默认否 | 整体连接与外观影响 |
| 增大镂空孔 | 局部调整移除区 | 否 | 孔洞附近材料是否被削弱 |
| 改建筑风格 | 固定地点和参考图，生成主体新版本 | 是 | 主体是否变化、全几何重检 |
| 圈选修改窗户等内容 | 蒙版约束编辑、合成、差异比较 | 通常是 | 选区外变化、重新矢量化与检查 |
| 撤销、恢复 | 恢复版本快照与参数 | 否 | 对应状态恢复，过期检查重算 |

不满意时保留现有成果，生成修改建议或新版本，不覆盖唯一原稿。无法可靠修复时建议增大尺寸、减少细节、调整结构或换图，不静默降级成表面雕刻。

### 6.3 一句话修改的执行规则

例如：「建筑不动，文字改成 LONDON 2026，相框窄一点。」

1. LLM 解析为文字修改与相框参数调整。
2. 后端校验参数、操作权限和目标版本。
3. 算法复用建筑几何，修改文字与相框，重新合并材料。
4. 重新检查，保存新版本，展示变化并支持撤销。

不为这类操作重生成整张图。不允许模型直接把任意代码或 SVG 当成可信操作执行。

局部模型编辑不保证选区外绝对不变。使用蒙版、合成、差异检测和用户确认控制范围，明显超出范围的结果可拒绝。用户主动修改真实建筑结构时，标明属于艺术改造。

## 7. 镂空算法：真正需要新增的核心

### 7.1 保持比例和明确坐标

当前 Potrace 分别将宽高缩放到 100，非方形输入可能被拉伸。应保存原图比例和变换，用统一缩放进入最终毫米画布。

不能仅靠正面视角 Prompt 保证比例正确。排版、文字、相框和用户编辑均使用明确的物理坐标。

### 7.2 合并材料后再提取切割边界

```text
建筑实体、孔洞 + 字形 + 框架 + 横条 + 连接桥
  → 应用最终毫米坐标变换
  → 按各元素填充规则解析材料
  → 布尔合并保留材料
  → 检测与局部修复
  → 重新合并并验证
  → 提取外边界与内部移除区域边界
  → 按明确加工流程处理刀缝并复核
  → 唯一切割轮廓与可选雕刻细节
```

当前相框、建筑、横条与字形只是多个 SVG 元素叠放。直接把填充改成描边，会把本来应该保留的重叠内部边也切开。必须先合并材料，再导出实际边界。

SVG 线宽不是材料桥宽，也不是实际刀缝。刀缝补偿只能由产品或下游软件中的明确一方负责，避免重复执行。

### 7.3 检查最终材料结构

至少包含：

- 几何有效，切穿边界闭合，无未处理自交和重复切线。
- 保留材料连接为一个整体；点接触、切线接触或一像素斜接不能直接判为可靠连接。
- 建筑与支撑、支撑与框、文字与支撑均满足配置要求。
- 最窄桥宽、孔洞和间隙按最终尺寸检查，不能用整条 path 包围盒代替。
- 材料合并与刀缝处理后再次检查，避免修复产生新的缺陷。
- 制作范围符合设备幅面，输出中存在实际有效开孔。
- 最终版本与检查配置对应一致，服务端控制制作包交付。

连通与足够强固是不同条件，几何通过与实物测试也分别记录。当前设备表中的数值需要补充来源和实测依据，不能直接当成已验证切割规则。

### 7.4 清理与修复避免损坏主体

- 保留清理前草稿，记录被删除区域；只留最大黑色连通域可能误删本可桥接的主体部位。
- 多轮廓必须分析嵌套，不能默认第一条以后全是孔洞。
- `holeCount` 和黑色占比不证明镂空可制作。
- 局部加粗不能堵死窗户或字母内孔；加桥后检查相邻区域。
- 修复尽量避开关键轮廓，无法保留辨识度时请求用户调整。

## 8. Prompt 和模型审计该怎么改

| 位置 | 修改目标 | 保证边界 |
| --- | --- | --- |
| 图像生成公共约束 | 黑色为保留材料、白色为候选开孔、单主体、避免孤岛和细弱连接 | 改善草稿，不能证明最终合格 |
| 实景转换 | 传入明确建筑与实际参考素材，区分原视角提取和正立面重构 | 正立面未见结构仍属于推断 |
| 场景 Agent | 简报携带镂空目标、尺寸及已知约束 | 不让语言模型替代几何计算 |
| 照片审计与反馈 | 去掉「黑色较多即不合格、移除实心填充」的线稿倾向，改看材料结构 | 黑色占比可辅助提示，不独立决定可切 |
| 生成后自然语言编辑 | 输出允许的结构化操作和目标版本 | 后端验证后执行 |

两个入口统一进入同一套镂空装配与检查。不能只修改文字入口的相框与切割导出，就声称照片入口也已支持实际镂空。

## 9. 作品模型、任务和版本

作品状态不能只存最终 SVG 字符串。建议至少包含：

```text
Project
  projectId / owner / accessPolicy
  subject: resolvedPlaceId / landmarkId / referenceAssetIds / mode
  canvas: physicalSize / units
  elements: subjectGeometry / text / frame / supports / bridges
  process: hollowCut / optionalEngrave / material / thickness / device
  versions: parentVersion / operation / snapshot
  checks: designVersion / profileVersion / algorithmVersion / results
  exports: designVersion / profileVersion / artifactIds
```

先实现建筑、文字、相框、支撑与连接桥独立编辑，不要求首发就识别每一扇窗。局部视觉内容可以先由用户选区定义。

正式服务必须做到：

- 长任务有任务 ID、真实阶段与刷新恢复，模拟百分比不当作真实进度。
- 重试有幂等控制，避免重复生成和重复计费。
- 旧任务不能覆盖更新版本，取消停止后续可停止步骤。
- 改尺寸、材料、几何或配置后旧检查失效。
- 下载文件对应当前确认版本，不在导出时静默替换设计。
- 几何编辑与图像重生成分别说明成本；收费操作执行前有清楚价格。
- 已支持素材、作品和导出持久保存，设定可理解的数据保留与删除方式。

## 10. 制作交付、隐私与验证等级

### 10.1 两类文件

- **设计文件：** 当前草稿或矢量设计，明确尚未通过哪些制作检查，允许用户保存。
- **制作包：** 针对具体配置的切穿文件、可选雕刻层、尺寸、检查结果与必要来源信息。

不能只给图层起一个名字就假定软件自动识别工艺。验证支持的软件与版本、导入比例、路径和加工模式。切割顺序若由软件决定，应通过实际导入配置验证，不假定 SVG 元素顺序等于机器顺序。

### 10.2 验证等级

| 状态 | 所需证据 |
| --- | --- |
| 设计草稿 | 生成与渲染成功 |
| 几何检查通过 | 最终版本、明确阈值来源与检查记录 |
| 导入验证通过 | 指定软件、版本、设置与检查结果 |
| 配置完成样件验证 | 设备、材料、厚度、参数与代表样件 |
| 当前作品完成实测 | 对应作品版本的实际加工记录 |

不能用某个材料配置做过样件，就宣称每件新作品已实测。对外承诺限定在真实验证范围内。

### 10.3 来源、隐私与分享

如实说明照片是否发往云端模型；原图、生成图、矢量和公开预览分别控制权限。公开分享由用户主动操作，使用真实版本链接和二维码，不默认泄露原图或制作文件。

素材保留与展示依据实际授权。用户实物反馈经授权关联作品和配置，用来改进桥接、简化、模板与材料规则；不默认转为公共素材或训练数据。

| 分享、进度与文案 | 真实任务阶段、版本链接、云端说明、镂空语义 | 前端、后端 |
| 待建立的作品服务 | 任务、资产、作品、版本、权限与制作包 | 后端、存储 |

不预先指定某个几何库作为答案。先验证布尔运算、曲线精度、嵌套轮廓、性能和许可，再选择最小可行实现。

## 12. 实施顺序与正式上线门槛

### A. 建立正确基础

1. 完成搜图 P0 和身份契约。
2. 确定镂空材料语义、物理坐标与作品结构。
3. 实现材料布尔合并、轮廓提取和基础切穿导出。
4. 同步修正 Prompt 与照片反馈，减少不适合镂空的草稿。

### B. 建立可编辑、可验证的完整流程

1. 文字、相框、尺寸独立编辑，保存与撤销。
2. 最终材料检测、局部修复预览与复核。
3. 两个入口统一装配、检查与制作包交付。
4. 持久任务、权限、费用与版本一致性。
5. 完成搜图 P1 与已覆盖地标的稳定素材交付。

### C. 验证后正式发布

1. 完成声明支持的软件导入与代表样件验证。
2. 对外明确设备、材料、尺寸、来源及验证范围。
3. 通过服务异常恢复、费用一致性和隐私访问测试。
4. 确保未通过结构检查时，不能导出标为已验证的制作包。

以上是正式镂空产品的必要步骤。不能将 B、C 中必要的制造能力推迟到上线后，再以表面雕刻代替。

首发之后再扩展任意局部风格修改、更多模板、系列作品和制作商接单。首发的一句话编辑可以先覆盖文字、框架、尺寸和受支持的修复操作。

## 13. 验收与产品展示

| 验收项 | 通过条件 |
| --- | --- |
| 地点一致 | 搜图、生成、重试、文字与来源均遵守已确认地点 |
| 主体不乱变 | 确定性编辑不调图像模型，保留基础建筑几何；布局变换单独记录 |
| 编辑有效 | 文字正确、缺字提示、参数受控，可对比和撤销 |
| 比例正确 | 非方形输入不会被无意拉伸 |
| 结构可检 | 孤岛、细桥、点接触、孔洞与刀缝影响在最终尺寸下检查 |
| 修复可信 | 标出改动位置，修复后重跑检查，不静默删除主体特征 |
| 导出正确 | 材料已合并，无重叠内部切线，预览与导出同版本同尺寸 |
| 恢复一致 | 刷新、失败重试和并发编辑不丢成果，不覆盖新版本 |
| 来源和隐私 | 实际参考图可追溯，公开预览不泄露私密原图 |
| 制作有证据 | 软件导入和代表样件对应明确配置，未实测不冒充实测 |

代表测试样本包括：建筑与框架连接、细塔尖、密集窗格、含内孔字形、长城市名、小尺寸、非方形参考图、照片主体不连通、重复轮廓与对角点接触。

用户体验中应直接展示：改文字而建筑不变、缩小后标出脆弱部位、接受连接修复、查看真实参考图、恢复上次版本、获得对应制作包。

记录有效编辑率、保存率、导出率、任务失败率、每次有效修改成本和已验证配置中的实际制作结果，不把出图数量当作产品价值的唯一指标。
