## 1. MakerMuse 是什么

| 维度 | 事实 |
|---|---|
| 定位 | 「AI 驱动的灵感与设计工具，专为创客打造」——输入文字/图片，产出**生产就绪**的 .SVG（激光切割）和 .GLB（3D 打印）文件 |
| 生态归属 | 与 Creality Falcon 激光机深度绑定（`crealityfalcon-laser.com/mm_tt` 为联合落地页）；起源于 1024 七牛黑客松的 Prompt Front Overflow 团队，MVP 已打通「文本 → 3D 模型 → 自动切片 → 一键发送打印机 → 实物验收」闭环 |
| 商业模式 | 场景工具当前**免费**（页面标题均为「AI 免费生成」），未公开定价页；推测策略是硬件生态引流 + 后续增值服务 |
| 产品结构 | 极简：场景库（主页）+ 单场景工具页 + 登录。没有仪表盘、没有社区、没有文件管理中心 |

### 1.1 场景工具的统一范式（13 个场景全部遵循）

每个场景 = 情绪化 landing 页 + iframe 向导式工具流：

```
Landing：情绪化大标题 + 「上传 → AI → 导出」三步图 + 开始按钮
   ↓
工具流（iframe 内多步向导）：
   上传（带 ✓/✗ 好/坏示例图引导）→ AI 处理 → 预览 → 下载生产文件
```

实例佐证：
- **萌宠王国**：「把你的猫变成波普艺术刻进木头里」→ 上传正面照（页面明确提示 ✓正面清晰 / ✗侧面 / ✗多只）→ 波普肖像 → 雕刻文件
- **双视角水晶**：编号步骤（01 人像 → 02 文字），上一步未完成下一步按钮 disabled
- **金雕生成器**：明确四步（生成图片 → 效果预览 → 矢量转换 → 下载文件），上传限 JPEG/PNG/WEBP ≤20MB
- **手写陶瓷**：「从杂乱照片中提取纯净矢量图」——本质就是城市木刻师照片入口的同类能力

## 2. 关键判断：这对城市木刻师意味着什么

### 判断一：平台选型完全正确，且时机是「现在」

城市木刻师的全部能力（AI → 生产就绪文件 → DFM）与 MakerMuse 的产品哲学**逐字吻合**。平台缺的正是城市木刻师这条「情绪叙事」最重的场景；城市木刻师缺的（账号、支付、设备生态、分发）恰好全部由平台补齐。互补性极强。

### 判断二：「你的城市肌理」是最大威胁，也是最好的谈判筹码

官方排期里已有城市主题场景，这正是城市木刻师要落位的地方。**作者在创想三维实习，本产品即「城市肌理」场景本身，无需差异化叙事**——这里只需明确：官方当前该场景是「敬请期待」的空位，城市木刻师 demo 要把它填实。

城市木刻师相对「城市肌理」的补强点是**精确性**：核心诉求从「情绪写意」升级为「地理/路网真实」——街道走向、街区形状、地标位置与真实地图一致。这需要新增真实地图数据底座（OSM/Overpass 路网），而非仅靠 AI 文生图。

### 判断三：接入后必须遵守的「场景范式」

按 1.1 的范式重构城市木刻师 UI，这是接入的硬门槛：
1. Landing 页要有**一句情绪化大标题**（城市木刻师现成：「把忘不掉的那座城，刻进木头里」）。
2. 上传必须带 ✓/✗ 引导示例（城市木刻师照片入口需补：✓主体清晰 / ✗多人 / ✗背景杂乱）。
3. 步骤编号化、逐步解锁（下一按钮依赖上一步完成态）。
4. 输出对齐平台文件规范：SVG 为主，命名、单位（mm）、图层语义需与平台其他场景一致。

## 3. 接入建议（按优先级）

### P0 · 决定成败

1. **补齐「场景范式」改造清单**（见判断三），把黑客松 UI 收敛为平台统一交互语言。
2. **新增地图数据底座**（本次最大新增）：地理编码（Nominatim）+ 真实路网矢量（Overpass）+ 投影/简化 + 道路分级，这是「地理/路网真实」的前提，demo 里完全没有（见 PRD 第 5.2 节）。
3. **实机验证先行**：借一台 Falcon 激光机实切路网稿 + 地标稿，把「切得出来 + 认得出」的照片证据作为上线验收标准（PRD M2 里程碑）。

### P1 · 上线质量

4. **链路移植**：DeepSeek ReAct、Qwen-Image、Potrace、DFM 四个核心模块已验证可复用（见 PRD 第 5 节交接表）；限流/账号/监控全部改用平台设施，不自建。
5. **三模式分层**：地图肌理（精确，主推）、地标场景（精确）、写意剪影（情绪兜底）——系统自动判定走哪条，用户可手动切换（见 PRD 第 2 节）。
6. **设备库对齐**：DFM 阈值库交由平台统一维护，城市木刻师只保留检查逻辑。
7. **合规补课**：OSM 数据 ODbL 授权、照片入口肖像提示、地标商用版权清单（埃菲尔夜景等）、隐私政策——进平台前法务必须过。

### P2 · 上线后增长

8. **数据回流**：借助平台账号体系，城市木刻师首次获得「同一用户多次生成」的数据，用于优化 prompt 与图库选品。
9. **分享卡对齐平台传播**：小红书分享文案里带「Made with MakerMuse」，帮平台证明场景价值，换推荐位。
10. **第二供应商评估**：Qwen-Image 单点依赖，接入平台后争取多模型路由能力。

---

## 4. 一页纸结论

- **做**：把城市木刻师重构为 MakerMuse 的「城市肌理」场景，核心是**地理/路网真实**，新增 OSM 地图数据底座，三模式分层（地图肌理 / 地标场景 / 写意剪影）。
- **先做**：OSM 路网链路打通 + 实机切割验证 + 场景范式 UI 改造。
- **不做**：自建账号/支付/监控（用平台的）；坚持星空灯；靠 AI 文生图硬造「不真实的地图」。
